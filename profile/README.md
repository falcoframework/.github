# Meet Falco.

Falco is a toolkit for building fast and functional-first web applications using F#.

[Docs](https://www.falcoframework.com/docs) · [Code](https://github.com/FalcoFramework/Falco) · [Samples](https://github.com/FalcoFramework/Falco/tree/master/examples) · [Help](https://github.com/FalcoFramework/Falco/discussions)

[Get Started](https://www.falcoframework.com/docs/get-started.html) · [Learn More](https://www.falcoframework.com/#falco)

[Latest release: 5.2.0 (December, 21, 2025)](https://www.nuget.org/packages/Falco)

## Fast & Lightweight

Optimized for speed and low memory usage. [Learn More](https://web-frameworks-benchmark.netlify.app/result?l=fsharp)

## Easy to Learn

Simple, predictable, and easy to pick up. [Get Started](https://www.falcoframework.com/docs/get-started.html)

## Native View Engine

Markup is written in F# and compiled. [See Examples](https://www.falcoframework.com/docs/markup.html)

## Customizable

Seamlessly integrates with ASP.NET. [Explore How](https://github.com/FalcoFramework/Falco/tree/master/samples/ScribanExample)
